Nexus swaps typical vector-clock comparisons for an optimized Lamport logical timestamp combined with client hash salting to achieve linear O(1) insertion lookups without traversal locks.

engine/crdt_resolver.rs 
pub fn resolve_insert(&mut self, op: &OpNode) -> Result<UpdateLog> {
    let mut cursor = self.origin_index.get_mut(&op.origin)?;
    while let Some(next) = cursor.next() {
        if next.lamport > op.lamport || 
          (next.lamport == op.lamport && next.client > op.client) {
            break;
        }
        cursor.advance();
    }
    cursor.splice(op.clone())
}

By shifting from JSON payload envelopes to custom variable-length zigzag LEB128 bit-packing, Nexus pruned outbound transport payloads by 65%, eliminating framing garbage collector churn.

transport/delta_frame.rs 
#[inline(always)]
pub fn encode_varint(mut val: u64, buf: &mut Vec<u8>) {
    while val >= 0x80 {
        buf.push((val as u8) | 0x80);
        val >>= 7;
    }
    buf.push(val as u8);
}
